# Autonomous RC Car

**High Speed Driving | Controlled Drifting | Autonomous Parking | Computer Vision**

## Project Overview

The Autonomous RC Car project aims to design, build, and program a small scale robotic vehicle that combines high performance remote controlled driving with autonomous navigation and computer vision capabilities.

The vehicle is intended to support high speed driving, controlled drifting, autonomous parking, object detection, distance sensing, wireless remote control, and live video streaming.

The project will integrate mechanical components, embedded systems, sensors, computer vision, and control algorithms to create a robotic platform capable of both manual and autonomous operation.
